# 出稿自检

- 一页纸能区分现在怎么做、哪里受阻与目标流程；缺失有标记，没有虚构现状。业务目标/价值逐项对应用户结果及已确认故事；未覆盖部分转成有目标锚点的待确认候选或由业务明确排除，不冒充事实，覆盖表无空白目标。
- 概览一眼可扫，每条故事能找到详情；场景按实际发生顺序排列，类型作为场景标签；业务规则位于具体场景内。按场景检查页面能力及需要业务确定的文案长度、枚举内容/数量、必填和校验反馈等规则，不编造数值。为独立阅读需要而重提的信息保持一致、精简，不机械重复。
- 风险遗漏场景先展示若不考虑的具体后果，再给场景详情；锚定已明确故事或未覆盖目标/价值，给出纳入/暂不考虑的决定；未知处理未伪装成承诺。
- 确认记录可按场景定位；每个未确认问题可直接作答，并说明为什么要确认、答到什么程度；不显示部门分组。待确认问题在场景内以红色折叠区展示，默认收起，展开可看完整问题、原因、标准及答复。当前状态仅“未确认 / 已确认”；有未决细节时整项标未确认，不显示部分确认或其他中间状态。已确认事项和最终版不显示确认原因、确认标准。
- 读者可逐条或全部展开、收起场景；关闭脚本仍能看详情；打印、筛选不改变确认记录。
- 阶段一报告内交叉引用链接都能跳到唯一且具体的目标；目标折叠时可自动展开。最终版正文不含引用超链，所有场景、规则、功能、边界、需求和验收均完整写出，并可通过按钮复制正文。只有真实答复且必要决定闭环才定版。中文简洁、专业、术语准确；标题层级、表格、流程步骤和状态标记帮助定位与比较，不以视觉装饰代替内容；页面不露出处。
